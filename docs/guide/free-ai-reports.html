Free AI reports

The dashboard can write a full report for any stock with a free AI, without Claude Code. One click gives you a summary, bull and bear cases, valuation, levels to watch and a swing-trade plan.

It tries free providers in this order and moves to the next if one is busy or out of free requests:

  1. Google Gemini (gemini-2.5-flash)
  2. Groq (openai/gpt-oss-120b)
  3. OpenRouter (a :free model)

You need at least one free key. Two or three is better, so you always have a backup. No key yet? The button still writes a basic report from the numbers, without AI.

Step 1: Get a free key​

Pick one or more. None of them need a credit card for the free tier at the time of writing. Free limits change, so check each site.

Google Gemini​

  1. Go to aistudio.google.com/apikey and sign in with a Google account.
  2. Click Create API key, then copy it.

Groq​

  1. Go to console.groq.com/keys and sign up (Google or email).
  2. Click Create API Key, give it a name like stock-analyst, then copy it. It's shown only once.

OpenRouter​

  1. Go to openrouter.ai/keys and sign up.
  2. Click Create Key, then copy it.
  3. Free models allow about 50 requests a day. A one-time $10 credit raises that to about 1,000; this is optional.

:::warning Keep keys private A key works like a password. Don't paste it into chats, screenshots, emails or GitHub. :::

Step 2: Add the key​

Keys go in a private file, keys.env, inside your data folder. Only this computer reads it.

Mac / Linux: open a terminal and run (this creates the file and makes it readable only by you):

touch ~/.stock-analyst/keys.env && chmod 600 ~/.stock-analyst/keys.env && open -e ~/.stock-analyst/keys.env

On Linux, replace open -e with nano.

Windows (PowerShell):

notepad "$HOME\.stock-analyst\keys.env"

Add one line per key you have, then save:

GEMINI_API_KEY=paste-your-gemini-key-here
GROQ_API_KEY=paste-your-groq-key-here
OPENROUTER_API_KEY=paste-your-openrouter-key-here

Leave out the lines for keys you don't have.

:::tip Prefer environment variables? Setting GEMINI_API_KEY (and the others) in your shell works too, and takes priority over the file. :::

Step 3: Restart the dashboard and check​

Stop the dashboard (Ctrl + C) and start it again:

uv run ~/.claude/skills/stock-analyst/scripts/dashboard.py --open --auto

The terminal should say Free AI reports: gemini (or whichever you added). Open any card and press Write report with free AI at the bottom of the panel. It takes up to a minute.

Everything in one command​

uv run ~/.claude/skills/stock-analyst/scripts/dashboard.py --open --auto

--auto keeps things up to date while the dashboard is open:

  • rescans your portfolio and watchlist every 30 minutes,
  • writes today's report for any of them that doesn't have one yet (up to 5 per pass, to save free requests),
  • shows progress in the Auto badge at the top of the page.

You can also write reports from a terminal:

uv run ~/.claude/skills/stock-analyst/scripts/report.py AAPL MSFT

What is sent to the AI​

SentNever sent
Ticker, price, 52-week range, moving averages, RSI, returnsYour holdings, quantities and costs
Public company figures (P/E, growth, margins, debt, analyst ratings)Your journal and past calls
The score, its factors and flagsYour profile and lessons
Recent news headlines and their linksYour API keys (each goes only to its own provider)

:::caution Free tiers may learn from what you send Some free tiers, including Gemini's, may use requests to improve their products, and people may review them. That's why only public market data is sent. :::

How much to trust these reports​

  • Each report is labelled Auto report with the model that wrote it.
  • The AI only sees the numbers and headline titles. It can't read articles, filings or earnings calls, so it misses context a full Claude report would find.
  • Every number in the text is checked against the data. Any that don't match are listed under Numbers to double-check at the end.
  • Auto reports never overwrite a report written by Claude.

Change models or limits (optional)​

Add to ~/.stock-analyst/config.json. Change only what you need:

{
  "llm": {
    "order": ["groq", "gemini", "openrouter"],
    "providers": {
      "groq": {"model": "llama-3.3-70b-versatile", "daily_limit": 100}
    },
    "auto_reports_per_run": 3
  }
}

daily_limit is a safety cap the dashboard counts locally, so one busy day doesn't use up a provider's free quota.

Troubleshooting​

You seeWhat to do
"no key set yet" in the terminalCheck the file is at ~/.stock-analyst/keys.env and the line starts with the exact name, e.g. GEMINI_API_KEY=
"key rejected (401)"The key was copied wrong or deleted. Create a new one
"rate limit or daily quota reached (429)"Free limit used up. The next provider is tried automatically; add a second key as a backup
"model not found (404)"The provider renamed or removed that free model. Pick a current one from its model list and set it in config.json
"basic report was written"No provider answered. The terminal shows why for each one
