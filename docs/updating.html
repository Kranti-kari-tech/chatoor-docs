Updating and uninstalling

Versions​

Each release has a version like 0.1.0, and its notes list what changed (see What's new for the plain-English version). Until 1.0.0 the tool is in early development: features can still change between releases. To see which version you have, look at the end of the line at the bottom of any dashboard page (for example "Chatoor 0.17.0"), or read the VERSION file in the skill folder.

When an update is ready​

While Chatoor is open it checks about every four hours whether a newer version has been published where you installed it from. When there is one, a bar appears under the top of the page — "Chatoor 0.19.0 is available. You have 0.18.0." — with How to update (it shows the one-line command for your computer) and a × to dismiss it until the next version. Updating always keeps your data.

Update to the latest version​

  1. Open a terminal and run:

    npx skills update stock-analyst -g -y

    You should see ✓ Updated stock-analyst, or All global skills are up to date if you already have the latest version.

  2. Restart Claude Code (type /exit, then claude) so it reads the new version of the skill.

  3. Using the dashboard? Stop it with Ctrl + C in its terminal, start it again, and refresh the browser page:

    uv run ~/.claude/skills/stock-analyst/scripts/dashboard.py --open

Installed the dashboard only? Paste its install line again; it fetches the newest release and keeps your data.

Your journal, portfolio, profile, lessons, watchlist and saved reports are kept. They live outside the skill, in ~/.stock-analyst/.

See what changed on the What's new page, or the detailed changelog.

How often should I update?​

Once a month is plenty. Updates add features and fix bugs. They never change your saved data, and they never change any scoring weights you set yourself.

See what's installed​

npx skills list -g

Uninstall​

npx skills remove stock-analyst -g

If the dashboard is running, stop it first. This removes the skill but keeps your data. To delete your data too, delete the ~/.stock-analyst folder.
